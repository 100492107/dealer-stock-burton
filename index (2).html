Cloud Sync Setup

Free shared storage so the same stock appears on every device. Takes about 2 minutes.

  1. Go to jsonbin.io and create a free account
  2. Click Create Bin, paste [] as the content, save
  3. Copy the Bin ID from the URL or bin details
  4. Open API Keys and copy your X-Master-Key
  5. Paste both below and click Save

After setup, host this page on Netlify Drop (drag the folder) to get a permanent link you can open on any phone or computer.
